# StockAZ — Market Intelligence Dashboard

[![Live demo](https://img.shields.io/badge/Live_demo-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://stock-tracker-hh1axzdlj-aytaj-s-projects1.vercel.app/)

A market-research workspace that organizes stock data, technical signals and portfolio context into a clearer decision-support experience.

## Product challenge

Investment research is often spread across charts, news, calendars and watchlists. StockAZ explores how these signals can be brought into one dashboard without losing the context behind a stock decision.

## Key capabilities

- Market overview, watchlists and stock comparison
- Interactive charts and technical indicators
- Earnings and economic-calendar views
- Analyst forecasts, valuation and sentiment panels
- Portfolio tracking, alerts and trading journal
- AI-assisted stock summaries and daily brief concept
- Responsive web plus Capacitor mobile structure

## Technology

`React` `TypeScript` `Vite` `Node.js` `Express` `Capacitor`

## Interview walkthrough

Start with the market overview, select a stock and move through technical, valuation and sentiment panels. Then review the watchlist, portfolio and alert workflows.

> Educational portfolio product using third-party and demo market data. It does not provide investment advice.
